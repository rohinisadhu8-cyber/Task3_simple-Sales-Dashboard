Simple Sales Dashboard — User Guide
Project Overview
The Sales Performance Dashboard provides an interactive view of sales performance by product category, region, and month. It helps users understand sales trends and identify high-performing areas.
Key Performance Indicators
Total Sales: Shows the total revenue generated.
Total Profit: Displays the total profit earned.
Total Units Sold: Shows the total quantity of products sold.
Top-Performing Region: Identifies the region generating the highest sales.
Dashboard Visuals
Sales by Region: Compares sales performance across different geographical regions.
Sales by Product Category: Identifies the product categories contributing the most to total sales.
Monthly Sales Trend: Displays changes in sales over time and helps identify monthly patterns.
How to Use the Dashboard
Users can select a region using the slicer to filter the connected PivotTables and charts. The date timeline can be used to examine sales over a selected period, provided it is connected to the relevant PivotTables.
Key Insights
The dashboard can help identify the strongest sales regions, best-performing product categories, and changes in monthly sales. Actual conclusions should be based on the results displayed by the dataset.
Tools Used
Microsoft Excel, PivotTables, PivotCharts, and interactive slicers.
Conclusion
This dashboard transforms raw sales data into a clear and interactive visual report, helping stakeholders monitor sales performance and make data-informed decisions.
